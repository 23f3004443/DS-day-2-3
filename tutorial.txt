now we start with docker, main idea of docker is that anyone shall be able to replicate your environment, your packages with exact versions as you use, to eliminate continuity error.

a docker image is a blueprint that contains all your libraries, binaries, images, code pieces while a container is a isolated running instance of that image.

first change host on app.run(host=0.0.0.0, port=5000) 
127.0.0.1 which is default on flask means only listen to self, own computer, nothing else
by changing it to 0.0.0.0 we are telling flask to listen to all open networks. 

now create docker file and write all the steps
first we should install python on linux server  created by docker, use python slim light and fast
then we set our working directory as /app on linux server (only some reserved keywords allowed like /service, /app)
then we move our requirements.txt to that location "." (current location)
then we run command pip install -r requirements.txt
then we copy our app.py and model.pkl inside current lcoation ./
then we expose the port 
lastly  we give command to start flask server that is python app.py in list format

here we are generating a docker script that tells docker step by step how to setup up the project in linux image.

FROM python:3.13-slim
WORKDIR /app 
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY app.py model.pkl 
EXPOSE 5000
CMD ["python", "app.py"]

we first build docker images using this command: 
docker build -t iris-api-image  (-t means tag names your image, else random weird hexadecimal name)

then we create a container from that image, also remember to change host and port:
docker create --name iris-api-container -p 127.0.0.1:5000:5000 iris-api-image

then we start the container:
docker start -a iris-api-container (use -a  if you want docker to take terminal and show live request output, -a means attach)
